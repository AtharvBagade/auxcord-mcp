# Two Hook-Point Logging: Source-Level API Errors and Tool-Level Call Outcomes

Spotify API failures are logged at their source in `SpotifyClient.request()` (all ~30 client methods funnel through this single chokepoint), independent of whether a calling tool later catches and self-heals the exception. A second, separate hook wraps MCP tool registration to log one line per successful call and a verbose block for any exception that escapes a tool uncaught. A single hook point is insufficient: per ADR-0001, player tools in `src/tools/playback.py` catch `HTTPStatusError` and return structured self-healing JSON instead of raising, so a tool-level-only hook would never see these as failures. Logging happens exclusively to stderr in plain text, since stdio transport uses stdout for JSON-RPC protocol frames.
